# 🤟 GESTURA - Indian Sign Language Detection UI

## 📱 Overview

GESTURA is a modern mobile application UI designed in Figma for Indian Sign Language (ISL) detection. The app enables users to recognize hand gestures, learn ISL, and improve communication through a clean and user-friendly interface.

## ✨ Features

- Home
- Gesture Detection
- Learn ISL
- About

## 🎨 Design Tool

- Figma
